Feedstock for [jana](https://github.com/JeffersonLab/JANA2) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

JANA2 is a C++ framework for multi-threaded HENP event reconstruction.

## Install

```bash
conda install -c hep-forge -c conda-forge jana
```
