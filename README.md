# jana-feedstock

[![Build AMD64](https://github.com/hep-forge/jana-feedstock/actions/workflows/autoupload.amd64.yml/badge.svg)](https://github.com/hep-forge/jana-feedstock/actions/workflows/autoupload.amd64.yml)
[![Build ARM64](https://github.com/hep-forge/jana-feedstock/actions/workflows/autoupload.arm64.yml/badge.svg)](https://github.com/hep-forge/jana-feedstock/actions/workflows/autoupload.arm64.yml)

Feedstock for [jana](https://github.com/JeffersonLab/JANA2) — part of [hep-forge](https://anaconda.org/hep-forge).

JANA2 is a C++ framework for multi-threaded HENP event reconstruction.

## Install

```bash
conda install -c hep-forge -c conda-forge jana
```
